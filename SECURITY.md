# Security

Supported versions: the latest pre-release only.

Report vulnerabilities privately via GitHub Security Advisories ("Report a
vulnerability"), with a reproduction that uses synthetic files.

In scope: any way reelwarden modifies scanned files, command or protocol
injection through file names passed to ffmpeg/ffprobe, network access,
overwriting unrelated files via `--output` or the cache, and plans that would
remove the only copy of data.
